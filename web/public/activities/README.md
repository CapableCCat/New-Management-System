# 活动照片（报名页轮播）

## 你要做的

把活动照片放进**本目录**，按下面的名字命名，**不用改任何代码**。

| 文件名 | 说明 |
| :--- | :--- |
| `01.jpg` | 第 1 张（轮播顺序按编号） |
| `02.jpg` | 第 2 张 |
| `03.jpg` | 第 3 张 |
| `04.jpg` | 第 4 张 |
| `05.jpg` | 第 5 张（最多 5 张，够用就行） |

- **支持格式**：`.jpg` / `.jpeg` / `.png`（同一张不要放多个格式，会重复显示）
- **编号必须连续**：放了 `01` 和 `03`、没有 `02`，那就只显示这 2 张 —— 不影响，只是不连续
- **建议尺寸**：横图，宽 1200px 左右、比例 16:9 或 4:3；单张 ≤ 500KB 加载更快
- **不用压缩到很小**：轮播是移动端首屏内容之一，太大影响打开速度

## 现在是什么状态

目前目录里**没有照片**，报名页的轮播区显示的是**占位块**（三张灰底「活动照片 1/2/3」），
这是社长要求的「先开发、占位符占位」。等你把照片放进来，占位块会**自动消失并换成真照片**，
一放就行，不需要重新改代码。

## 为什么不用"清单文件"

早期方案是维护一个文件名清单，但那样每加一张照片都要改代码。现在改成**按固定编号探测**：
页面加载时探一下 `01`~`05` 有没有文件，有就显示。代价是每张候选会发一次请求
（没命中就是 404，很轻；且结果在**一次页面加载内只探测一次**，不会反复请求）。
